# Background music

Place your audio file here as **`ambient.mp3`**.

The site's splash screen ("Start Exploring" button) starts this track when the
visitor enters, and the floating music button in the bottom-right corner lets
them pause or resume it.

If `ambient.mp3` is missing, the button simply does nothing — no errors are
shown to visitors. Supported formats: MP3, WAV, OGG, M4A. MP3 is recommended
for the widest browser support and smallest file size.
